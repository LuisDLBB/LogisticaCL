# Pago a Proveedores

Módulo independiente dentro de LogisticaCL. Comparte usuarios, empresas, permisos y la base multitenant del proyecto principal.

## Alcance previsto

- Proveedores, agencias y repartidores externos.
- Servicios ejecutados y su evidencia operacional.
- Tarifas de pago por cobertura, cliente, servicio y peso.
- Adicionales, descuentos y documentos tributarios.
- Revisión operacional, aprobación y fecha de pago.
- Trazabilidad del pago y rentabilidad del servicio.

Las tablas se crearán cuando estén validadas las reglas de pago para agencias regionales, repartidores de Santiago y proveedores de regiones.

La definición funcional, reglas validadas y pendientes se mantiene en `docs/modules/provider-payments.md`.
